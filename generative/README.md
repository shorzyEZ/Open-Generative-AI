# flowfilm — генеративное кино без API

Фильм, который целиком живёт в коде: **сид → векторное поле (fBm-шум) → 3000 частиц
оставляют светящиеся следы → bloom, зерно, виньетка → кадры уходят в ffmpeg**.
Звук тоже синтезируется кодом: дрон, квинта, шумовой «ветер», редкие колокольчики
на пентатонике.

Ни API-ключей, ни GPU, ни интернета. Только `numpy`, `pillow` и `ffmpeg`.

```
python3 generative/flowfilm.py --seed 21 --palette ink \
  --seconds 12 --width 1280 --height 720 --particles 3000 \
  --out out/film.mp4 --poster out/film.png --audio
```

| Флаг | Что делает |
|---|---|
| `--seed N` | **другой фильм**. Один и тот же сид = один и тот же фильм, всегда |
| `--palette` | `ember` (закат), `ink` (ночной океан), `neon` (киберпанк), `moss`, `bone` |
| `--particles` | плотность потока: 800 — эскиз, 3000 — картина, 6000 — органика |
| `--seconds`, `--fps` | хронометраж |
| `--audio` | синтезировать саундтрек (WAV, тот же сид — та же музыка) |
| `--poster` | «отпечаток» фильма — один кадр в 1.9× разрешении |

## Рендер в облаке, без установки

В репозитории есть `.github/workflows/render-film.yml`:

1. **Actions → Render film → Run workflow** → выбрать сид, палитру, длительность → Run.
2. Через 1–3 минуты в ветке `media` появится `generated/<name>.mp4` и `.png`.
3. Ссылка на скачивание: `https://github.com/<user>/<repo>/raw/media/generated/<name>.mp4`

Или пушем «сценария» — файл `films/<имя>.json`:

```json
{ "name": "night-tide", "seed": 21, "palette": "ink",
  "seconds": 8, "fps": 24, "width": 1280, "height": 720,
  "particles": 3000, "audio": true }
```

Шаблон: `films/example.json`. Один пуш = один фильм.

## 8 задач-челленджей (от простого к дикому)

Каждая — маленький PR, по одной идее за раз. Именно так и учатся.

1. **Новая палитра.** Добавь в `PALETTES` словарь `abyss` — и сними фильм в нём.
2. **Разные скорости.** Сейчас `speed` одна на всех. Сделай зависимость от `age`,
   чтобы частицы «разгонялись» к концу жизни.
3. **Kaleidoscope.** Отрази кадр по вертикали и горизонтали (`arr = np.minimum(arr, arr[:, ::-1])`).
4. **Feedback.** Держи предыдущий кадр и подмешивай 3% — начнётся дым и шлейфы.
5. **Свои титры.** Пауза на первом кадре + надпись (см. `scripts/make_animatic.py`,
   там титры рисуются PIL'ом, потому что `drawtext` есть не в каждом ffmpeg).
6. **Музыка по картинке.** Передай в `soundtrack()` среднюю яркость кадров —
   пусть громкость и высота тона следуют за движением.
7. **Вертикаль.** `--width 720 --height 1280` для Reels/Shorts: композиция рассыпется,
   и это интересная задача — как её удержать.
8. **Галерея.** Собери страницу GitHub Pages: постер + плеер на каждый фильм из `media`.

## Как это связано с остальным репозиторием

`flowfilm` — «нулевой бюджет»: он рисует **абстракции**, а не людей. Для фигуративного
видео в этом же репозитории есть два других пути:

- `jobs/` + `.github/workflows/generate-video.yml` — нейро-видео через MuAPI (нужен ключ и кредиты);
- `scripts/make_animatic.py` — монтаж готовых кадров: наезды, кроссфейды, титры (бесплатно);
- `generative/flowfilm.py` — генеративная графика из математики (бесплатно, без GPU).
